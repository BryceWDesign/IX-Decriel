# Authors

## Origin and primary author

**Bryce Lovell**

Bryce Lovell originated and created **Decriel**, a security-first programming
language designed around declarative effects, explicit capabilities, runtime
integrity, evidence, and least-authority.

## Repository identity

**IX-Decriel** is the official public research repository for **Decriel**.

The `IX-` prefix identifies this repository as part of the IX research ecosystem.
It does not change the language name. The language itself is **Decriel**.
